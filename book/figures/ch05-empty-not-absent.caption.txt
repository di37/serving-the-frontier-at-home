Absent, defined-empty, and defined are three different states to NCCL. A defined-but-empty `NCCL_IB_GID_INDEX` parses as GID index 0 and, because NCCL loads `/etc/nccl.conf` with `overwrite=0`, also masks the config file — a hazard Compose makes structural by always defining the key. The stack defuses it twice: the launcher deliberately emits the empty value so it out-substitutes a stale pin in the worker's own `.env.dspark`, and the shared entrypoint unsets every defined-empty variable before `exec`, so what reaches NCCL is truly absent. The same contract governs the four fabric passthrough knobs.
